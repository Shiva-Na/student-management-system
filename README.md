# Student Management System API

## Features
- CRUD Operations
- RESTful APIs
- Layered Architecture
- Validation & Exception Handling

## Tech Stack
- Java
- Spring Boot
- Hibernate / JPA
- MySQL

## API Endpoints
- GET /students
- POST /students
- PUT /students/{id}
- DELETE /students/{id}

## How to Run
1. Clone repo
2. Run using IntelliJ / Maven
3. Test APIs in Postman
